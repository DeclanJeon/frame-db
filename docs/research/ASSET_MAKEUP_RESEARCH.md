# FRAME DB 메이크업·그루밍 에셋 확장 조사

조사·접근일: **2026-10-30**. 이 문서는 조사와 제작 설계만 수행한다. 이미지 생성, DB 변경, 유료 서비스 사용은 수행하지 않았다.

## 1. 결론과 범위

**제품 사진을 늘리기보다, 기존 기술 항목을 조합한 얼굴 완성 룩과 동일 조건 비교 이미지를 먼저 만든다.** 권장하는 유한한 1차 범위는 기본 레시피 22개(얼굴 12, 얼굴 그루밍 6, 네일 4), 파생 레시피 38개(얼굴 24, 그루밍 6, 네일 4, 상태 4), 합계 **60개 레시피**다. 이는 이 프로젝트의 작업 상한 제안이지, 세상에 존재하는 메이크업 종류의 총수가 아니다. 레시피와 DB 엔트리, 이미지 장수는 서로 다른 단위다.

근거의 구분:

- **관찰**: 로컬 export의 ID·제목·설명·상태·연결 레코드.
- **출처 사실**: 아래 공식 브랜드 교육 본문에 실제로 적힌 기법과 구분. 브랜드의 설명이지 독립적인 임상·성능 검증은 아니다.
- **설계 제안**: 기본/파생 레시피, 촬영 수치, 프롬프트 필드, 장수, 우선순위. 브랜드가 이 분류나 수량을 인증한 것은 아니다.

다양한 피부색, 눈꺼풀 형태, 연령, 수염 성장 패턴에 같은 배치를 강요하지 않는다. 기존 DB의 성별 라벨은 재고 기록으로만 보존하고, 후속 제작에서는 성인 정체성·원래 얼굴 구조·사용 목적을 기준으로 선택한다. 주근깨 유지, 물방울, 네일, 타투는 모두 “완성 얼굴 메이크업”과 같은 종류가 아니다.

## 4. 에셋 분류와 중복 방지

다음은 출처의 기법을 정리한 **프로젝트용 분류 제안**이다. 완성 룩과 구성 기술 사이에는 다대다 연결을 둔다.

| 종류 | 기록할 단위 | 기존 예시 | 대표 이미지 |
| --- | --- | --- | --- |
| 기술 | 선·레이어·블렌딩·정돈 방식 | 소프트 윙, 컨실러, 브로우 | 같은 얼굴의 해당 부위가 읽히는 뷰 |
| 마감 | 반사 위치·면적·확산·광택 강도 | 윤광, 매트, 새틴 립 | 동일 조명 아래 피부·입술 |
| 색/배치 | 색 계열·명도·채도·농도·경계·적용 영역 | 피치/로즈 치크, 브론저 | 얼굴 위 발색과 마스크 |
| 완성 룩 | 베이스+눈+치크+립+눈썹의 고정 조합 | 피치 데일리, 레드 립, 스모키 | 머리 전체와 턱선이 보이는 얼굴 |
| 그루밍 | 길이·밀도·결·연결·면도 경계 | 스터블, 콧수염, 풀비어드 | 정면과 양쪽 사선 |
| 상태/연속성 | 땀·물·기존 점·타투 등의 위치 | 운동 후, 비, 타투 위치 고정 | 기준과 비교 가능한 동일 부위 |

S1·S3·S4의 상품명은 기법을 찾는 색인으로만 쓴다. 얼굴에 발린 결과와 제품 용기 사진은 대체 관계가 아니다. 프로젝트 분류에서는 브론저의 색과 마감을 다른 축으로, 피치의 립/치크/눈 배치를 다른 레시피로 구분한다. 반대로 “윤광”과 “dewy”처럼 차이가 없는 번역·별칭을 새 기본 룩으로 세지 않는다.

## 7. 후속 이미지 제작: 얼굴 중심의 통제 조건

이 절의 수치와 허용 조건은 **프로젝트용 촬영/생성 규격 제안**이며 위 브랜드의 표준 수치가 아니다. 아직 이미지 생성이나 육안 검수를 한 결과가 아니다.

### 얼굴·그루밍·상태 공통

1. **기준 인물**: 사용 승인을 받은 동일 성인 정체성. 얼굴 비율, 피부 바탕색, 점·주근깨 위치, 원래 비대칭, 눈·입·코·턱 형태 고정. 수염 비교에는 동일한 성장 패턴 기준을 사용한다.
2. **프레이밍**: 세로 4:5, 납품 제안 1600×2000 px. 정수리부터 턱 아래·어깨 윗부분까지 포함, 얼굴 높이 약 65–75%, 정수리·턱·귀 잘림 없음. 눈높이 카메라, 85 mm 상당의 인물 원근감을 기준으로 하되 생성 프롬프트의 렌즈 숫자가 실제 광학 보증은 아님을 기록한다.
3. **뷰 3개**: 정면 0°, 좌사선 30°, 우사선 30°. 고개 pitch/roll 0°를 기준으로 하고 표정은 편안한 닫힌 입, 눈은 자연스럽게 뜬 상태. 눈/립 디테일은 원본에서 읽혀야 한다. 닫힌 눈 추가 컷은 이 장수에 포함하지 않는다.
4. **환경**: 중성 회색 무광 배경, 확산된 중성광(목표 5600 K), 정면 위쪽의 넓은 주광과 고정 보조광. 좌표·크기·거리·출력비를 세션 설정으로 기록한다. 실촬영은 노출/WB/톤커브 수동 고정과 컬러 타깃 확인, 생성은 고정 조명 지시 및 결과 대조를 사용한다.
5. **스타일 고정**: 머리는 얼굴 바깥으로 정리하고 헤어라인·의상·귀걸이 유무·배경·크롭·카메라 거리 동일. 컬러 조명, 역광 드라마, 과노출, 피부 스무딩, 뷰티 리쉐이핑은 비교군에서 제외한다.
6. **실험 단위**: 기준 → 기본 → 파생을 같은 뷰끼리 비교. 변경 마스크 밖의 얼굴과 표정, 톤매핑이 바뀌면 색/마감 차이라고 해석하지 않고 재작업한다. 스플릿 페이스는 양쪽 얼굴 비대칭 때문에 기본 평가 방식으로 쓰지 않는다.
7. **실제 검수**: 정면에서 배치·눈썹/입술 경계, 사선에서 반사·수염 연결, 확대에서 피부결·털·색 경계 확인. 매트는 모공 삭제가 아니고 컨투어는 턱 형상 변경이 아니다. 물·땀은 위치/형태가 읽혀야 하며 단순 전면 광택으로 대체하지 않는다.

조명·WB 통제가 안 되면 “웜톤 변형”, 노출이 달라지면 “윤광 감소”, 얼굴이 달라지면 “컨투어 효과”라는 결론을 내리지 않는다. 같은 seed나 렌즈 문구만으로 동일 인물·동일 조명을 보장했다고 기록하지 않는다. 생성 이미지는 측색이나 실물 제품 발색 검증 자료가 아니다.

- 네일은 얼굴 프레임에 끼워 넣지 않는다. 동일 손 기준, 위에서 보는 전체 손톱 뷰 1개 + 45° 사선 1개, 같은 손톱 길이·바닥 형태·손가락 배치·광원·배경을 고정한다. 손톱 끝과 큐티클이 보이게 하며 손가락별 패턴 지도를 기록한다.

### 예시 A: 얼굴 완성 룩 가이드

```text
recipe_code: L03
parent_entry_ids: FS-0033, CRAFT-makeup-894f4e90c90a,
  CRAFT-makeup-25aad27693a2, CRAFT-makeup-144e623f091c
목표: 얇은 베이스 위에 피치 치크와 절제된 브라운 눈을 둔 데일리 룩.
순서: 얇은 베이스 → 지정 영역 보정 → 자연 브로우 →
  얇은 브라운 라인 → 피치 치크 경계 블렌딩 → 투명 립밤.
고정: 승인된 성인 얼굴, 원래 피부색·점·눈꺼풀·입술 윤곽.
피치 영역: 양 볼의 지정 마스크 안. 코·턱에는 색을 추가하지 않음.
검수: 정면에서 치크 배치, 사선에서 반사와 경계,
  확대에서 피부결과 눈/입술 모양 보존.
근거: S1의 치크 배치·블렌딩. 전체 조합과 순서는 FRAME DB 설계 제안.
```

### 예시 B: 나중에 사용할 이미지 생성 프롬프트

```text
승인된 동일 성인 기준 얼굴을 사용한 메이크업 비교 사진.
L03: 피부결이 보이는 얇은 베이스, 지정한 볼 영역의 은은한 피치,
속눈썹 뿌리의 얇은 브라운 라인, 결을 살린 자연 눈썹,
원래 입술색 위 얇은 투명 립밤. 점·주근깨와 원래 비대칭을 유지한다.
이번 출력은 정면 0도, 편안한 닫힌 입, 눈을 자연스럽게 뜬 상태.
정수리부터 턱 아래와 어깨 윗부분까지, 세로 4:5,
눈높이 카메라, 중성 회색 배경, 고정된 넓은 확산 중성광.
기준 이미지와 헤어·의상·크롭·노출·화이트밸런스를 일치시킨다.
제품 용기·브러시·손·로고·텍스트·장신구를 추가하지 않는다.
얼굴 리쉐이핑, 피부 미백, 모공 삭제, 렌즈/눈동자 변경,
입술 확대, 과한 인조 광택, 새로운 주근깨를 만들지 않는다.
```

이것은 프롬프트 예시이며 이미지 생성 요청을 제출한 기록이 아니다. 이미지 편집형 도구라면 기준 참조와 변경 마스크가 입력에 실제로 연결되었는지 후속 실행에서 확인한다.

### 예시 C: 장면에 적용하는 사용 프롬프트

```text
선택한 성인 캐릭터의 얼굴·체형·피부색·점·주근깨·눈썹 기점과
입술 윤곽을 유지한다. FS-0033 피치 데일리 레시피를 적용하되,
화장 색소와 지정 부위의 반사만 변경한다.
치크는 승인된 볼 마스크, 눈은 얇은 브라운 라인,
립은 자연색 위 얇은 촉촉함으로 한정한다.
장면의 기존 광원 방향·화이트밸런스·피부 질감을 따른다.
헤어·의상·표정·카메라 구도와 얼굴 구조는 바꾸지 않는다.
```

카탈로그 이미지 프롬프트는 비교를 위해 촬영 환경을 고정하지만, 사용 프롬프트는 기존 장면을 유지한다. 실제 장면을 회색 스튜디오로 덮어쓰지 않도록 두 목적을 분리한다.

## 9. 실행 순서와 이번 조사 완료 기준

1. 기존 42개 ID를 유지하고 기본 22개 레시피의 구성 관계를 검토한다. 특히 전체 윤광/국소 하이라이트, 브론저/컨투어, 브로우 정돈/얼굴 룩을 중복 엔트리로 만들지 않는다.
2. 후속 이미지 작업에서 기준 정체성·손·수염·도안과 미확정 길이/색/마스크를 먼저 잠근다. 기본 67개 슬롯을 계획하고 실제 결과를 보고 통과분만 연결한다.
3. 기본 비교가 성립한 뒤 파생 38개를 작업한다. 의미 없는 재명명이나 동일하게 보이는 파생은 새 종류 수로 부풀리지 않는다.
4. 피부색·얼굴 형태·연령 다양성을 늘릴 때는 각 인물의 자체 기준과 비교한다. 서로 다른 인물 간 색차를 화장 효과로 해석하지 않는다.

이번 조사 완료: 정확한 로컬 재고 42개, 읽을 수 있었던 공식 본문 6개, 기본/파생 수량과 구성 관계, 통제 촬영 규격, 가이드·이미지·사용 프롬프트 필드를 문서화했다. 마감·브론저/컨투어 후보 본문은 접근 실패를 명시하고 검증된 외부 사실에서 제외했다. 미완료로 남긴 것은 사용자가 나중에 요청할 실제 이미지 제작·출력 검수·DB 반영이다. 이번 작업 범위에서 그 실행은 요구되지 않았다.
