# FRAME DB 미디어 확장 설계

기준일: 2026-10-29. 이 문서는 현황 분석과 실행 제안이다. 신규 이미지·영상·음성을 제작하거나 빈 DB를 확보 완료로 바꾸지는 않는다.

후속 사용자 지시: Drive 이전과 홈페이지 검증을 마친 뒤, 29개 분류 전체를 웹 정보로 채우는 설계와 분류별 실행 예약을 먼저 진행한다. 아래의 신규 미디어 제작 파일럿은 별도 제안이며 이 지시만으로 유료 생성이나 대량 제작을 시작하지 않는다.

## 1. 현재 자료의 컨셉

현재 라이브러리는 작품 감상용 사진 모음보다 **제작 요소를 분리해 비교하는 레퍼런스 보드**에 가깝다.

- 포즈: 흰 배경의 얼굴 없는 선화 마네킹, 관절과 중심선, 자세·접촉·인물 간 관계. 같은 포즈를 정면·하이·로우·측면·사선으로 묶는다.
- 의상: 회색 배경에서 얼굴과 머리를 생략한 코디 일러스트. 실루엣·배색·레이어링·아이템 조합을 비교한다. 일부 신체 표현이 남아 있지만 인물 정체성 자료는 아니다.
- 자체 도식: 조명·카메라·카메라 이동의 설명 그림. 실제 촬영 결과나 실제 움직임 샘플로 취급하지 않는다.

**헤어·메이크업은 현재 포즈·의상 이미지에서 추출해 채울 수 없다.** 모발과 얼굴 정보가 없기 때문이다. 별도의 얼굴·헤어 기준 자료를 제작하거나 확보해야 한다. 포즈·의상의 배경 제거와 비교 용이성은 유지하되, 해당 분야를 판단할 수 있는 관찰 영역을 추가한다.

시각 관찰은 포즈 4계통과 의상 8분류에서 각 1개, 총 12개 썸네일을 직접 확인한 결과다. 전체 이미지에 대한 시각 검수 완료를 뜻하지 않는다.

## 3. 공통 데이터 단위

기존 연결을 유지한다.

`categories → reference_entries → entry_variants → media_assets`

- 기본 항목: 사용자가 독립적으로 선택할 수 있는 스타일·기법·행동·제작 개념.
- 변형: 같은 개념의 다른 방향·적용 인물·상태·촬영 조건.
- 파일 표현: 원본·표시용·썸네일. 다른 항목이나 다른 각도로 세지 않는다.
- 가이드: 제작 지침. 이미지를 붙여도 가이드라는 성격을 유지한다.
- 도식: 개념 설명 자료. 실사·영상·오디오의 대용 수량으로 계산하지 않는다.

기존 45개 헤어와 40개 메이크업 항목에서 중복 개념을 먼저 점검한다. 동일 개념의 자료를 확보하면 기존 ID를 보강하거나 명시적인 관계를 연결한다. 기존 초안·가이드를 임의 삭제하거나 확보된 자료인 것처럼 상태만 바꾸지 않는다.

### 제안하는 기록 계약

초기 파일럿은 `entries.details`, `variants.attributes`, `prompt_templates.parameters`, `import_batches.report`를 사용한다. 아래 값이 현재 모두 구현되어 있다는 뜻은 아니다.

| 묶음 | 기록할 정보 |
| --- | --- |
| 형태 | 분야별 구조·색·질감·적용 조건 |
| 정체성 | 기준 인물·기준 이미지 ID, 얼굴 비율·특징 위치, 고정·변경 허용 요소 |
| 관찰 | 원본 설명 / 직접 관찰 / 측정 / 미확인 / 설계 제안 구분 |
| 계보 | 제작·수집 방식, 도구·모델·버전, 프롬프트, 참조 입력, 편집 내역 |
| 출처 | 제작자, 원출처 URL·ID, 취득일, 이용 조건 원문·증빙 |
| 매체 | 이미지 해상도·크롭 / 영상 길이·FPS·구간 / 음성 언어·길이·화자·조건 |
| 파일 | Drive ID·폴더, SHA-256, 원본과 파생본 관계 |
| 검수 | 실제 검사 파일·구간, 검사자·날짜, 발견 오류·수정 결과 |

검색과 공개 판정을 좌우하는 값은 실제 적재·표시 경계에서 검증한다. JSON 설명을 추가하는 것만으로 승인 흐름이 구현되었다고 보지 않는다.

현재 신규 항목 등록 API는 텍스트 초안만 만든다. 이후 별도 작업으로 미디어 적재와 검수 승격 경로가 필요하다.

## 4. 헤어 파일럿

### 시각 규격

- 얼굴·목·어깨가 보이는 기술 일러스트형 레퍼런스. 현재 코디 보드와 어울리는 단색 중성 배경.
- 정면·측면·후면의 동일 인물·동일 커트. 머리와 모발 끝이 프레임 밖으로 잘리지 않게 한다.
- 얼굴·피부·의상·조명은 고정하고 헤어 구조만 바꾼다.
- 피사체 기준 좌우, 헤어라인, 가르마, 앞·옆·뒤 길이, 귀·목덜미 노출을 기록한다.
- 모발 질감은 관찰 가능한 범위로 표시하며 추정 밀도나 보이지 않는 구조를 사실로 쓰지 않는다.

### 분류 축

커트 계열 / 길이 / 레이어 / 앞머리 / 가르마 / 묶음·업두 / 컬 구조 / 볼륨 위치 / 색·광택 / 건조·젖음·바람 상태.

길이·앞머리·묶음·컬을 모든 조합으로 곱하지 않는다. 실제로 구분되는 대표 스타일을 먼저 선정한다. 같은 커트의 색상 변경과 다른 인물 적용은 변형이다.

**제안 파일럿: 최대 24개 기본 스타일 × 필수 3뷰 = 최대 72개 원본.** 썸네일과 표시본은 여기서 파생한다. 추가 시점은 구조가 가려져 판정할 수 없을 때만 만든다. 이 수량은 제작 제안이며 생성 완료나 지출 승인이 아니다.

## 5. 메이크업·그루밍 파일럿

### 시각 규격

- 동일 인물·동일 조명·동일 화이트밸런스의 기준 상태와 적용 후 비교.
- 얼굴 전체로 배치를, 필요한 확대 이미지로 눈·입술·피부결·수염 경계를 확인한다.
- 얼굴 비율·점·주근깨·흉터·피부결을 고정한다. 다른 얼굴이나 다른 광원을 화장 효과로 오인하지 않게 한다.
- 얼굴 없는 마네킹 대신 정체성이 고정된 성인 가상 인물 기준 세트나 사용 범위가 명확한 촬영 자료를 사용한다.

### 분류 축

적용 영역 / 커버리지 / 경계 처리 / 라인 형태 / 색상·명도·채도 / 매트·윤광·글리터 / 배치 / 유지할 특징 / 촬영·색보정 조건.

얼굴 화장, 수염 정리, 네일, 신체 표식 보존은 하위 분류를 나눈다. 완성 룩과 개별 기법을 함께 제공할 때는 적용 관계를 연결하고 같은 이미지를 신규 확보량으로 이중 계산하지 않는다.

**제안 파일럿: 최대 16개 구별되는 기법·룩.** 각 룩은 적용 후 정면·사선과 판정에 필요한 영역 확대를 기본으로 한다. 기준 인물별 무화장 기준 세트는 공통 자료로 연결하며 룩마다 복제 집계하지 않는다. 색상만 바꿔 16개를 채우지 않는다.

### 매체를 억지로 이미지에 맞추지 않는다

- 행동·모션·카메라 이동·립싱크는 영상이 필요하다. 포스터 프레임은 검색용이지 동작 검수의 증거가 아니다.
- 목소리는 실제 음색, 말투는 정확한 대사와 연기 조건, 소리는 실제 청취 가능한 파일이 필요하다.
- 동일 보이스의 다른 문장, 동일 음악의 다른 압축본은 새로운 기본 항목이 아니다.
- 기획·운영·근거·인계·QA는 장식 이미지보다 실제 문서·결과물·검수 사례가 중요하다.

```text
        └── camera-motion/
```

각 분류 아래 `01_thumbnails`, `02_display`, `03_originals` 중 필요한 폴더만 둔다. 기존 포즈는 썸네일·PNG 원본 2종, 의상은 썸네일·표시 WebP·PNG 원본 3종, 도식은 SVG 원본을 보존한다.

이전 범위는 외부 수집 파일 7,099개와 자체 SVG 68개, 총 7,167개다. 파일명·원출처·Drive 파일 ID·해시를 매핑해 폴더를 이동하거나 사람이 파일명을 보고도 원본을 추적할 수 있게 한다.

이후 헤어·메이크업은 별도 분야 폴더에서 `entry_id/view_id`를 포함한 이름을 사용한다. 검수 전 작업물과 실제 홈페이지 연결 파일은 구분한다.

## 8. 배치 수용 기준

1. 실제 파일이 존재하고 열리며 출처·원본·Drive ID·해시가 연결된다.
2. 기본 항목, 각도·적용 변형, 썸네일·압축 표현을 분리 집계한다.
3. 파일럿 납품 파일 전부를 직접 시각 검수한다. 영상은 관련 시간 구간, 오디오는 실제 청취를 포함한다.
4. 세트 내 정체성과 고정 조건이 유지되고, 선언한 요소만 바뀐다.
5. 원본 설명과 직접 관찰이 충돌하면 감추지 않고 각각 기록한다.
6. 홈페이지는 실제 미디어 확보량, 도식, 가이드와 초안 수를 별도로 표시한다.
7. 로딩 실패·권한 오류·미검수 상태를 빈 이미지나 확보 완료로 위장하지 않는다.
8. 생성 도구·비용·참조 자산·사용 범위를 확정한 다음 제작을 시작한다. 이 설계만으로 유료 생성이나 대량 신규 제작을 실행하지 않는다.

Drive 이전과 실제 이미지 표시를 먼저 안정화한 뒤, **헤어 24개와 메이크업 16개의 목록·기준 인물·예시 1세트를 승인하는 작업**을 별도로 진행한다. 그 예시가 통과하면 같은 계약으로 나머지를 제작·검수·적재한다. 처음부터 29개 분야를 같은 방식으로 수천 개씩 채우지 않는다.
